\section{Resumo}

\begin{frame}{Resumo}

\begin{itemize}
\item Modelo: \textbf{TSDF\_seqKANSeq} em modo \textbf{KAN-only} (sem MLP decoder, sem VAE, sem miss-head, sem status/static).
\item Entrada do backbone: $u_t = [x_t, m_t] \in \mathbb{R}^{2C}$ (concatenação de dados e máscara).
\item Backbone: \textbf{SeqKANSeq} com recorrência via splines univariadas e \textbf{top-k estrutural} opcional.
\item Treino: reconstrução supervisionada (MSE). 
\item Métrica reportada: Teste MSE (média $\pm$ erro padrão).
\end{itemize}

\end{frame}

\section{Metodologia}
\begin{frame}{1. Estrutura Geral (no TSDF\_seqKANSeq)}

No modo \textbf{KAN-only}, a entrada do backbone é:

\[
u_t = [x_t, m_t] \in \mathbb{R}^{2C}
\]

onde $m_t$ é a máscara feature-wise (1=observado, 0=ausente).

\medskip

O backbone SeqKANSeq implementa a recorrência:

\[
h_t = \mathrm{KAN}_{cell}\big([u_t, h_{t-1}]\big),
\quad
h_t \in \mathbb{R}^{H}
\]

com $H=\texttt{hidden\_dim}$ e $u_t \in \mathbb{R}^{2C}$.

\end{frame}
% --------------------------------------------------
\begin{frame}{2. Seleção Estrutural Top-k (Condicional)}

A esparsidade estrutural é aplicada apenas se:

\begin{itemize}
\item \texttt{topk.enabled = True}
\item \texttt{topk.kind = structural}
\item \texttt{epoch > warmup\_epochs}
\end{itemize}

\medskip

A máscara é construída a partir de um \textbf{score estrutural} por aresta:

\[
\text{score}_{ij}
=
\begin{cases}
\|\alpha_{ij\cdot}\|_1 \\
\|\alpha_{ij\cdot}\|_2
\end{cases}
\]

onde \( \alpha_{ij\cdot} \) são os coeficientes da spline na aresta \(i \to j\).

\medskip

A nova máscara seleciona as maiores conexões segundo o score,
\textbf{respeitando a máscara base do ArticleKAN}:

\[
M^{new}_{ij}
=
\mathbf{1}_{\text{top-k}} \cdot
\mathbf{1}_{M^{base}_{ij} > 0}
\]

\end{frame}

% --------------------------------------------------
\begin{frame}{3. Separação Estrutural Entrada / Estado (Célula)}

No caso da célula recorrente, se definidos:

\[
k_x = \texttt{topk.k\_x},
\quad
k_h = \texttt{topk.k\_h}
\]

a seleção é feita separadamente sobre \textbf{entrada} $u_t$ e \textbf{memória} $h_{t-1}$:

\medskip

\[
h_{t,j}
=
\sum_{i \in \mathcal{S}_j^{(u)}} s_{ij}(u_{t,i})
+
\sum_{l \in \mathcal{S}_j^{(h)}} s_{lj}(h_{t-1,l})
\]

com:

\[
|\mathcal{S}_j^{(u)}| \le k_x,
\qquad
|\mathcal{S}_j^{(h)}| \le k_h
\]

\medskip

Implementação no código:

\begin{itemize}
\item Primeiras \texttt{input\_size} linhas $\Rightarrow$ entrada do backbone ($u_t$)
\item Próximas \texttt{hidden\_size} linhas $\Rightarrow$ estado anterior ($h_{t-1}$)
\item Seleção top-$k_x$ e top-$k_h$ feita por coluna (por neurônio oculto)
\end{itemize}

\medskip
Obs.: O número efetivo pode ser menor caso a máscara base já restrinja conexões.

\end{frame}

% --------------------------------------------------
% --------------------------------------------------
\begin{frame}{4. Forma da Spline por Aresta}

Cada aresta ativa implementa:

\[
s_{ij}(u)
=
\sum_{m=1}^{M} \alpha_{ijm} B_m(u)
\]

onde:

\begin{itemize}
\item \( B_m(u) \): base B-spline de ordem \(k\)
\item \( \alpha_{ijm} \): coeficientes aprendidos
\item nós definidos por \texttt{grid} e \texttt{grid\_range}
\item \texttt{grid\_eps}: controla mistura entre grid uniforme e adaptativo
\end{itemize}

\medskip

O neurônio completo:

\[
h_{t,j}
=
\sum_{q \in \mathcal{S}_j}
\sum_{m=1}^{M}
\alpha_{qjm} B_m(v_{t,q})
\qquad \text{com } v_t = [u_t, h_{t-1}]
\]

\end{frame}

% --------------------------------------------------
\begin{frame}{5. Propriedade Estrutural}

Para cada neurônio:

\[
h_{t,j} = \sum_i s_{ij}(z_{t,i})
\]

Logo,

\[
\frac{\partial^2 h_{t,j}}
{\partial z_{t,i} \partial z_{t,r}} = 0
\quad (i \neq r)
\]

\begin{itemize}
\item Sem interações cruzadas diretas por aresta
\item Estrutura aditiva e interpretável
\end{itemize}

\end{frame}


% --------------------------------------------------
\begin{frame}{6. Saída: Reconstrução Direta $\hat{x}_t$}

No TSDF\_seqKANSeq (KAN-only), a reconstrução é produzida diretamente por heads KAN:

\[
\hat{x}_{t,k} = \mathrm{KAN}^{(k)}_{\text{out}}(h_t),
\quad
\mathrm{KAN}^{(k)}_{\text{out}}:\mathbb{R}^{H}\rightarrow\mathbb{R}
\]

com \texttt{width} $=[H,1]$ e $k=1,\dots,C$.

\medskip

Com top-k estrutural (\texttt{kind=structural}), cada saída usa no máximo:

\[
|\{j: M^{(k)}_j=1\}| \le k_{out}
\]

após \texttt{warmup}, respeitando a máscara base do ArticleKAN.

\end{frame}

% --------------------------------------------------
% --------------------------------------------------
\begin{frame}{7. Interpretação como Sistema Dinâmico}

A célula define a recorrência:

\[
h_t = F(u_t, h_{t-1})
\]

onde $F : \mathbb{R}^{2C+H} \to \mathbb{R}^{H}$.

Se \(x_t = 0\), obtemos um sistema autônomo:

\[
h_t = F(h_{t-1})
\]

Logo, o SeqKAN define um:

\begin{block}{Sistema Dinâmico Discreto Não Linear}
\[
h_{t+1} = F(h_t)
\]
\end{block}

Características estruturais:

\begin{itemize}
\item Dinâmica aditiva (não multiplicativa)
\item Não há matriz de recorrência linear \(W_h\)
\item A não linearidade está distribuída nas arestas
\item Interações cruzadas ocorrem apenas via soma no estado
\end{itemize}

\end{frame}


% --------------------------------------------------
\begin{frame}{8. Forma Matricial com Máscara Estrutural Dinâmica}

Representação com máscara dependente da época:

\[
h_{t,j}
=
\sum_{i=1}^{2C}
M_{ij}^{(u)} s_{ij}(u_{t,i})
+
\sum_{l=1}^{H}
M_{lj}^{(h)} s_{lj}(h_{t-1,l})
\]

onde:

\begin{itemize}
\item $M$ é atualizada dinamicamente após \texttt{warmup}
\item A seleção pode ser:
\begin{itemize}
\item \textbf{per-output}: top-k por coluna
\item \textbf{global}: top-k global na camada
\end{itemize}
\item Na célula: possível separação explícita entre $k_x$ e $k_h$
\end{itemize}

\medskip

A máscara estrutural não altera os coeficientes,
apenas zera conexões fora do top-k.

\end{frame}

% --------------------------------------------------
\begin{frame}{9. Implicações Estruturais}

\begin{itemize}
\item Funções explícitas por feature (splines univariadas por aresta)
\item Controle estrutural via top-k (opcional)
\item Sistema dinâmico não linear com esparsidade estrutural
\item Ausência de interação cruzada direta dentro da aresta KAN
\item Separação explícita entre contribuição de $x_t$ e memória $h_{t-1}$
\end{itemize}

\end{frame}

% --------------------------------------------------
\begin{frame}{Conclusão}

SeqKANSeq implementa:

\[
h_t = F(u_t, h_{t-1})
\]

com:

\begin{itemize}
\item Não linearidade distribuída nas arestas (B-splines)
\item Recorrência explícita sem gates multiplicativos
\item Esparsidade estrutural opcional via top-k
\item Estrutura aditiva interpretável
\end{itemize}

Resultados mostram desempenho comparável ao GRU,
com maior controle estrutural.

\end{frame}
