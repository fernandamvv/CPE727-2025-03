\section{Resumo}
\begin{frame}{Resumo}
\begin{itemize}
\item Objetivo: avaliar o modelo seqKAN para reconstrução de séries temporais industriais buscando maior interpretação.
\item seqKAN: modelo baseado em splines B-spline para modelar relações não lineares e temporais.
\item Metodologia: treino supervisionado com loss de reconstrução, usando métricas MSE e SE.
\end{itemize}
\end{frame}

\section{Metodologia}
\begin{frame}{1. Estrutura Geral da Célula}

A célula implementa:

\[
h_t = \mathrm{KAN}_{cell}([x_t, h_{t-1}])
\]

onde:

\[
x_t \in \mathbb{R}^{C}, 
\quad
h_{t-1} \in \mathbb{R}^{H}
\]

Entrada concatenada:

\[
z_t = [x_t, h_{t-1}] \in \mathbb{R}^{C+H}
\]

\end{frame}

% --------------------------------------------------
\begin{frame}{2. Forma Funcional por Neurônio}

Para cada neurônio oculto \( j \in \{1,\dots,H\} \):

\[
h_{t,j} = \sum_{i \in \mathcal{S}_j} s_{ij}(z_{t,i})
\]

onde:

\[
\mathcal{S}_j \subset \{1,\dots,C+H\}
\]

\[
|\mathcal{S}_j| = k_x + k_h
\]

Cada \( s_{ij}(\cdot) \) é uma B-spline univariada aprendida.

\end{frame}

% --------------------------------------------------
\begin{frame}{3. Separação Estrutural Entrada / Estado}

Imposição estrutural:

\[
\mathcal{S}_j = \mathcal{S}_j^{(x)} \cup \mathcal{S}_j^{(h)}
\]

com:

\[
|\mathcal{S}_j^{(x)}| = k_x
\quad
|\mathcal{S}_j^{(h)}| = k_h
\]

Portanto:

\[
h_{t,j}
=
\sum_{i \in \mathcal{S}_j^{(x)}} s_{ij}^{(x)}(x_{t,i})
+
\sum_{l \in \mathcal{S}_j^{(h)}} s_{lj}^{(h)}(h_{t-1,l})
\]

\end{frame}

% --------------------------------------------------
\begin{frame}{4. Forma da Spline por Aresta}

Cada aresta ativa implementa:

\[
s_{ij}(u)
=
\sum_{m=1}^{M} \alpha_{ijm} B_m(u)
\]

onde:

\begin{itemize}
\item \( B_m(u) \): base B-spline de ordem \(k\)
\item \( \alpha_{ijm} \): coeficientes aprendidos
\item nós definidos por \texttt{grid} e \texttt{grid\_range}
\end{itemize}

O neurônio completo:

\[
h_{t,j}
=
\sum_{i \in \mathcal{S}_j}
\sum_{m=1}^{M}
\alpha_{ijm} B_m(z_{t,i})
\]

\end{frame}

% --------------------------------------------------
\begin{frame}{5. Propriedade Estrutural Importante}

Como as funções são univariadas e somadas:

\[
\frac{\partial^2 h_{t,j}}
{\partial z_{t,i} \partial z_{t,r}}
=
0
\quad
\text{para } i \neq r
\]

Implica:

\begin{itemize}
\item Não há interação cruzada direta entre variáveis dentro do mesmo neurônio.
\item A interação ocorre apenas via soma no nível do estado.
\end{itemize}

\end{frame}

% --------------------------------------------------
\begin{frame}{6. Camada de Saída}

Para cada saída \( y_{t,k} \):

\[
y_{t,k}
=
\sum_{j \in \mathcal{T}_k}
r_{jk}(h_{t,j})
\]

com:

\[
|\mathcal{T}_k| = k_{out}
\]

Cada \( r_{jk} \) também é uma spline univariada.

\end{frame}

% --------------------------------------------------
% --------------------------------------------------
\begin{frame}{7. Interpretação como Sistema Dinâmico}

A célula define a recorrência:

\[
h_t = F(x_t, h_{t-1})
\]

onde \(F : \mathbb{R}^{C+H} \to \mathbb{R}^H\).

Se \(x_t = 0\), obtemos um sistema autônomo:

\[
h_t = F(h_{t-1})
\]

Logo, o SeqKAN define um:

\begin{block}{Sistema Dinâmico Discreto Não Linear}
\[
h_{t+1} = F(h_t)
\]
\end{block}

Características estruturais:

\begin{itemize}
\item Dinâmica aditiva (não multiplicativa)
\item Não há matriz de recorrência linear \(W_h\)
\item A não linearidade está distribuída nas arestas
\item Interações cruzadas ocorrem apenas via soma no estado
\end{itemize}

\end{frame}

% --------------------------------------------------
\begin{frame}{8. Forma Matricial com Máscara Estrutural}

Representação equivalente:

\[
h_{t,j}
=
\sum_{i=1}^{C}
M_{ij}^{(x)} s_{ij}(x_{t,i})
+
\sum_{l=1}^{H}
M_{lj}^{(h)} s_{lj}(h_{t-1,l})
\]

onde:

\begin{itemize}
\item \(M\) é a máscara estrutural top-k
\item Cada neurônio possui exatamente \(k_x + k_h\) conexões ativas
\end{itemize}

\end{frame}

% --------------------------------------------------
\begin{frame}{9. Implicações Estruturais}

\begin{itemize}
\item Modelo interpretável (funções explícitas por feature)
\item Controle estrutural via top-k
\item Sistema dinâmico não linear esparso
\item Interação entre variáveis ocorre apenas via estado
\item Separação clara entre contribuição de \(x_t\) e memória \(h_{t-1}\)
\end{itemize}

\end{frame}

% --------------------------------------------------
\begin{frame}{Conclusão}

A célula SeqKAN implementa:

\[
h_t = F(x_t, h_{t-1})
\]

com:

\begin{itemize}
\item Funções univariadas spline
\item Esparsidade estrutural controlada
\item Dinâmica recorrente explícita
\item Alto grau de interpretabilidade
\end{itemize}

\end{frame}
